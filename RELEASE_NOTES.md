# v1.0.0

First public-ready build of Skills Prompt Manager.

## Highlights

- Desktop workspace for managing AI skills and reusable prompts.
- Multi-source skill index for Claude, Codex, and Agents skill folders.
- File tree browsing and editing for skill packages.
- Markdown preview with separated frontmatter and body sections.
- Syntax-highlighted preview for common code files.
- Prompt body copy action that excludes YAML frontmatter.
- Unsigned Windows installer for the first release.

## 中文摘要

Skills Prompt Manager 首个版本提供本地 AI Skills 与 Prompts 管理工作台，支持多来源 skills 索引、文件树编辑、Markdown/frontmatter 分区预览、常见代码文件高亮预览，以及一键复制 prompt 正文。首版 Windows 安装包未签名。
